# Administrator Training

## Duration

1 to 2 hours

## Objectives

The administrator session ensures the customer can safely configure, operate, and support the queue system in a production environment.

## Agenda

### 1. System overview
- queue flow
- counter and service configuration
- dashboard and operational reporting

### 2. System configuration
- organisation and branding setup
- timezone and business hours
- queue names and service definitions
- operational rules and queue priorities

### 3. User management
- create users
- assign roles
- review access rights
- manage inactive or removed users

### 4. Queue configuration
- create and update services
- create counters
- assign staff to counters
- configure queue rules and service flow

### 5. Reporting and monitoring
- review daily queue activity
- monitor service demand
- identify bottlenecks
- investigate repeated queue issues

### 6. Troubleshooting
- login problems
- queue not appearing
- staff assignment errors
- display sync issues
- database and HTTPS problems

## Training outcome

By the end of the session, the customer administrator should be able to:

- configure services and counters
- manage user roles
- review queue operations
- perform an emergency recovery or reset when needed
- contact support with a clear description of the issue

## Handover confirmation

The customer must confirm they understand the system and are comfortable performing the administrator role before go-live.
