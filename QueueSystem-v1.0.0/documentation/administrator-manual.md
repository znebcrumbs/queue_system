# Administrator Manual

## Overview

This manual is for the person responsible for configuring and maintaining the QueueSystem environment.

## Dashboard

The dashboard provides a summary of current queue activity, service status, and operational health. Use it to review:

- active counters
- queue load
- service performance
- staff state
- today's operational summary

## User management

Administrators can manage:

- user accounts
- access roles
- staff assignments
- queue permissions

Always assign the minimum permissions needed for each role.

## Roles

Common roles include:

- administrator
- supervisor or manager
- staff
- kiosk or service user

Review access rights before go-live and ensure each user can only access the sections they need.

## Services and counters

Configure:

- queue services
- ticket prefixes
- queue rules
- counters
- staff assignments

Use clear naming conventions so staff and customers understand each queue flow easily.

## Reports

Use reporting to monitor:

- queue throughput
- service waits
- staff performance
- operational bottlenecks

## System settings

Key settings include:

- organisation branding
- queue naming
- timezone and operating hours
- kiosk configuration
- security settings

## Brand configuration

Set the organisation name, contact information, colours, and any queue display branding before customer rollout.

## Common issues

### Staff cannot log in

Check that the account is active and that the correct role is assigned.

### Queue not appearing

Confirm the service has been configured and enabled.

### Display not updating

Check browser refresh, network access, and system health.

## Support expectations

Keep backups, review logs, and maintain an active administrator contact for support escalation.
