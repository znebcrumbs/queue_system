# Handover Checklist

## Before go-live

- [ ] customer administrator identified
- [ ] service configuration reviewed and approved
- [ ] staff roster confirmed
- [ ] counter assignments confirmed
- [ ] domain and HTTPS configuration verified
- [ ] backup procedure tested
- [ ] admin login tested
- [ ] queue workflow tested end-to-end
- [ ] support contact and escalation steps confirmed

## Training completion

- [ ] administrator training completed
- [ ] staff training completed
- [ ] handover notes provided
- [ ] troubleshooting guide delivered
- [ ] support policy shared
- [ ] customer acceptance signed or recorded

## Acceptance record

The customer should confirm that:

- the system is operating as expected
- the administrator understands the configuration responsibilities
- staff understand standard queue operations
- escalation and support paths are clear

## Final sign-off

- [ ] production environment approved
- [ ] customer acceptance recorded
- [ ] maintenance agreement issued if applicable
- [ ] go-live date confirmed
