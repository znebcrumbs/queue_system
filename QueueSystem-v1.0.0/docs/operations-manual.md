# Operations Manual

## Starting work

1. Log in with your staff account.
2. Confirm the queue is active for the current day.
3. Review the service counters assigned to you.
4. Ensure the display and kiosk are working.

## Logging in

Use your assigned staff credentials and complete the login flow via the secure application portal.

## Calling the next customer

- select the queue service
- confirm the next customer is waiting
- call the customer to the appropriate counter
- monitor the service flow and queue count

## Recalling, skipping, and holding tickets

The system supports operational actions such as:

- recall a previously called ticket
- skip a ticket if the queue rule allows it
- hold a ticket when additional processing is required

Use these actions only when the workflow requires them.

## Completing and transferring

When a service interaction is complete:

- mark the ticket as completed
- confirm the next queue item is ready to call

If a transfer is required, follow the configured service-transfer workflow and verify the target queue is available.

## Handling mistakes

If an incorrect ticket was called or an item was completed in error:

- review the queue log
- revert or correct the action according to the operational rules
- communicate with the administrator if the issue affects service flow

## End-of-day procedure

- review queue activity for the day
- confirm all counters are closed correctly
- archive or export reporting data as required
- secure the workstation before sign-off

## When the system is unavailable

If the application is unavailable:

- advise customers and staff that the system is offline
- use the fallback queue process approved for that location
- notify the administrator and record the outage
- resume standard operation once the system is back online
