# Maintenance Agreement (Template)

## Scope

This agreement provides maintenance and support for QueueSystem for the licensed customer environment.

## Included services

The maintenance agreement may include:
- software updates and compatibility fixes
- bug triage and issue resolution
- security review and update coordination
- technical support for agreed deployment environments
- release review and update guidance

## Excluded services

Excluded unless separately stated:
- custom software changes
- hardware support
- network infrastructure support
- third-party hosting support
- major feature development

## Service levels

Service levels should be documented for:
- critical incidents
- business-hours support
- response times
- restoration targets
- escalation process

## Support responsibilities

The customer should be responsible for:
- infrastructure access
- secure environment configuration
- backups and restore testing
- disaster recovery coordination

The supplier should be responsible for:
- maintenance updates provided under the agreement
- technical support and issue triage
- release and rollback guidance where applicable

## Renewal and termination

Include the renewal period, notice requirements, and termination rights.

## Legal note

This template should be reviewed by a qualified legal adviser before use with customers.
