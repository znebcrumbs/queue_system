# Pricing Structure

## Self-Hosted License

AUD $5,000 to $8,000

Includes:
- QueueSystem software license
- installation documentation
- deployment guidance
- commercial license terms
- onboarding assistance
- initial technical support

## Managed Deployment

AUD $8,000 to $12,000+

Includes everything in the self-hosted license plus:
- environment setup
- database configuration
- domain and HTTPS setup
- system configuration
- branding setup
- queue configuration
- production testing
- go-live support
- handover and training

## Maintenance

AUD $300 to $750 per month

Includes:
- bug fixes under the maintenance scope
- security update review
- dependency updates
- technical support
- compatibility and issue resolution
- update coordination

## Custom Development

Quoted separately

Examples include:
- custom integrations
- advanced workflow requirements
- new reporting features
- hardware integration
- multi-branch configuration
- export or API work beyond the baseline scope

## Pricing notes

- pricing should be stated in AUD
- support terms should be defined in writing
- custom work should be scoped with a separate statement of work
- use the same pricing sheet for every customer to preserve repeatability
