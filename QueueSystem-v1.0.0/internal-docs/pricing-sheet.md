# QueueSystem Pricing Sheet

## License and Deployment Pricing

### Self-Hosted License
- AUD $5,000–$8,000
- includes software license, documentation, onboarding support, and technical guidance

### Managed Deployment
- AUD $8,000–$12,000+
- includes environment setup, deployment, configuration, testing, branding, and handover

### Maintenance
- AUD $300–$750 per month
- includes issue support, bug review, security update review, compatibility fixes, and update coordination

### Custom Development
- quoted separately
- includes integrations, custom workflows, advanced reporting, and custom product work

## Notes

- pricing is stated in AUD
- support terms should be defined in the customer agreement
- custom work is not included in the standard packages
- each deployment should be scoped before invoicing
