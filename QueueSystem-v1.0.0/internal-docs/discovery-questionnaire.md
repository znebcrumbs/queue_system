# Discovery Questionnaire

## Business details

- organisation name
- industry and service type
- primary location
- number of branches or sites
- customer volume per day

## Operational requirements

- queue services required
- expected number of counters
- number of staff users
- current queue process and pain points
- peak period expectations

## Technical requirements

- hosting preference
- domain and HTTPS requirement
- database preference
- desired deployment model
- preferred support and maintenance package

## Branding and configuration

- organisation name and branding requirements
- preferred queue naming
- display or kiosk requirements
- signage requirements

## Security and compliance

- expected data-hosting location
- internal IT contact
- admin ownership and support structure
- backup and incident-handling expectations

## Commercial decisions

- timeline for rollout
- budget expectations
- preferred license model
- support and maintenance preference
- training requirements
