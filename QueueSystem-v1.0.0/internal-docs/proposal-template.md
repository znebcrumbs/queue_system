# QueueSystem Customer Proposal

## Executive Summary

QueueSystem is a queue management application designed to improve service flow, reduce waiting time, and support efficient operational staffing for customer-facing service desks.

## Scope

This proposal covers:
- software licensing
- installation and configuration support
- deployment guidance or managed deployment
- queue configuration and service setup
- admin and staff onboarding
- user training and handover

## Customer Requirements

- organisation name
- service environment
- expected number of counters and staff
- queue services and staffing model
- deployment environment and hosting model
- training and support requirements

## Solution Components

- queue ticketing workflow
- counter and service management
- role-based staff access
- queue reporting and performance visibility
- secure deployment configuration

## Commercial Terms

### Self-Hosted License
AUD $5,000–$8,000

### Managed Deployment
AUD $8,000–$12,000+

### Maintenance
AUD $300–$750 per month

## Delivery Timeline

- discovery and requirements review
- proposal approval
- deployment and configuration
- user training
- go-live and handover

## Assumptions

- customer provides hosting or approved environment access
- customer provides business and queue configuration details
- customer IT contacts support the domain, database, and deployment setup
- final support terms are governed by the signed commercial agreement

## Acceptance

This proposal is subject to a signed agreement and confirmation of the deployment scope before production launch.
