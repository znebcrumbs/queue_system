# Application Source

This folder is the application bundle for the QueueSystem release. The source code is maintained in the project repository and is intended to be deployed as part of the licensed installation package.

## Included in the release

- Django application source for core queue workflows
- secure production configuration templates
- environment-based deployment settings
- admin and operator user flows
- queue and kiosk operational logic

## Deployment note

The actual application source should be deployed from the licensed repository or approved archive in accordance with the installation guide and the customer support terms.
