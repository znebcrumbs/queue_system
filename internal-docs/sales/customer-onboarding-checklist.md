# Customer Onboarding Checklist

## Pre-sale

- [ ] discovery call completed
- [ ] requirements reviewed
- [ ] proposal issued
- [ ] commercial license or order form reviewed
- [ ] pricing and scope approved

## Deployment readiness

- [ ] customer environment access provided
- [ ] domain and DNS confirmed
- [ ] database configured
- [ ] TLS certificate ready
- [ ] environment variables completed
- [ ] admin user created
- [ ] queue services configured
- [ ] counters and staff assigned

## Training and handover

- [ ] administrator training completed
- [ ] staff training completed
- [ ] operational manual delivered
- [ ] support policy shared
- [ ] customer sign-off recorded

## Go-live

- [ ] production check completed
- [ ] backup process in place
- [ ] incident support path confirmed
- [ ] maintenance agreement issued if applicable
