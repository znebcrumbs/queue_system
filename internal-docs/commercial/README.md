# Commercial Package

This folder contains the commercial and sales documents for the QueueSystem v1.0.0 baseline release.

## Included documents

- pricing.md — pricing structure for self-hosted and managed deployment
- license-agreement.md — commercial license template for customer use
- maintenance-agreement.md — support and maintenance terms
- proposal-template.md — sales proposal structure
- discovery-questionnaire.md — discovery and requirements intake form

## Important note

These documents are operational templates for a commercial rollout. They are not a substitute for formal Australian legal review before entering into a binding B2B agreement.
